# Project visuals

Ready-to-use PNG images for LinkedIn, the project README, and other posts.

- `linkedin-overview.png`: square overview explaining delegation from WhatsApp to T3 Code.
- `readme-workflow.png`: wide illustration showing a task sent from WhatsApp, work in T3 Code on your computer, and a requested file returned to chat.

These are AI-generated illustrations, not screenshots of a live session. They contain fictional examples and no account details. The existing project logo is in `../logo.png`.

## Suggested post caption

I built T3 WhatsApp: a WhatsApp companion for T3 Code.

Send a task from your own account in an existing chat, group, or Message yourself. T3 Code handles the work on your computer, and you can ask for progress updates or files back in WhatsApp.

Work stays in T3 by default. Your computer needs to stay awake and online with T3 Code running.

The visuals show illustrative conversations, not live screenshots.
